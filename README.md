# Diplom_3 Автотесты для UI сервиса "Stellar Burgers"

Написаны автоматизированные тесты с помощью Selenium с применением Page Object.
Тесты описаны с помощью Allure, в проекте присутсвует папка с результатами тестов (allure-results)
Ссылка на сервис: https://stellarburgers.education-services.ru/

Проверена основная функциональность:
- переход по клику на "Конструктор"
- переход по клику на раздел "Лента заказов"
- появление всплывающего окна с деталями при клике на ингредиент
- закрытие окна с деталями игредиента
- увеличение счётчика ингредиента при добавлении его в заказ

Раздел "Лента заказов":
- при создании нового заказа счётчики "Выполнено за все время" и "Выполнено за сегодня" увеличиваются (применена параметризация)
- после оформления заказа его номер появляетя в разделе "В работе"

Для написания тестов использовались библиотеки: pytest, allure, selenium

Команда для установки зависимостей из requirements: pip install -r requirements.txt

Команда для генерации Allure-отчёта: allure serve allure-results
